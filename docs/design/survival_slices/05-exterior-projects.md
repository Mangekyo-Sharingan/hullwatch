# Slice 05 — Exterior projects

Date: 2026-10-09. Status: planned. Operator approved the six activity directions and requested implementation to begin with slice 01; detailed values below are design choices to refine, not measured balance.

## Player sequence

Prepare an EVA, fit a useful external utility, connect/isolate it, repair damage and verify its operation from physical controls.

## Implementation steps

1. Choose one functional installation supported by prior slices: probe mount, collector or supplemental array; avoid a catalog before one works.
2. Use generated geometry and current hardpoints; pin footprints, service reach, tether routes and collision.
3. Charge materials, fitting/operating power and relevant heat/storage impacts; damaged connections must be diagnosable.
4. Provide manual isolation and recovery when power is down.
5. Save installed state, condition and job ownership; cancellation/refunds obey existing approved construction policy.

## Connections

Utilities extend survey/supply capabilities and ship configurations; salvage provides fittings; maintenance keeps them operating.

## Acceptance

- An installed utility enables a new action and changes real system budgets.
- Accessible installation, service, teardown and reload work with EVA/tether/airlock constraints.

## Ownership and verification

State belongs in existing simulators or a small domain simulator where needed; data-driven definitions, typed events, fixed-tick behavior and save migration are required. Pin exact file/API ownership before delegated edits. Use deterministic scenarios and actual scene interactions; report exact commands/PASS markers when run. Do not treat historical tests, screenshots or a generated dashboard as current verification.
